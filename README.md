# Trendscope

Trendscope was an experiment in AI-assisted / "vibe coded" SaaS development: a trend-intelligence tool aimed at short-form video markets (TikTok and similar), inspired by Greg Isenberg's IdeaBrowser prompt series. The idea was to build something closer to a Bloomberg Terminal for fast-moving social video trends — a system that could help creators, agencies, and short-form operators spot emerging patterns before they became obvious or saturated. Real implementation work went into scraping, trend detection, monitoring, and alerting, with a Next.js frontend and a Supabase-backed architecture.

The project never reached a finished public release: the landing page and dashboard remained incomplete and the trend-ranking logic needed more refinement. It is not under active development.

## Archived

This repository is archived. The code and history have been removed for security hygiene (the history contained credentials that needed to be scrubbed, and rewriting history was the simplest way to guarantee they are fully gone rather than just removed from the current tip).
